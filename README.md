## 📝 Descrição do Projeto
O GreenTech OS é um protótipo de painel administrativo (Dashboard SaaS) focado no mercado Agritech e no rastreamento "seed-to-sale" (da semente à venda). 

O projeto foi desenvolvido como requisito acadêmico para demonstrar a aplicação prática de componentização, responsividade e integração de Design Systems em aplicações React modernas. A interface simula o monitoramento de estufas, dados de sensores (temperatura/umidade) e previsões baseadas em Inteligência Artificial para otimização de colheitas.

## 🛠️ Tecnologias Utilizadas
* **React** (Biblioteca principal)
* **Vite** (Ferramenta de build e servidor de desenvolvimento)
* **Tailwind CSS v4** (Estilização utilitária e Dark Mode nativo)
* **shadcn/ui** (Arquitetura de componentes acessíveis)
* **Lucide React** (Iconografia temática)
* **Framer Motion** (Animações fluidas de interface)

## ⚙️ Instruções de Execução

1. Clone o repositório:
```bash
git clone [https://github.com/asapnyell/greentech-dashboard.git]
```

2. Acesse a pasta do projeto:
```bash
cd dashboard-cannabis
```

3. Instale as dependências:
```bash
npm install
```

4. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

5. Acesse no navegador:
O projeto estará rodando localmente em `http://localhost:5173`.
